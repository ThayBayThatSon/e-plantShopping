# Paradise Nursery Shopping Application

## Project Overview
**Paradise Nursery** is a dynamic, user-friendly e-commerce web application built with React and Redux Toolkit. It allows users to browse a wide variety of houseplants grouped into specialized categories, view plant details (images, names, descriptions, and prices), and manage their shopping cart with real-time quantity and total cost updates.

## Key Features
- **Landing Page:** Welcoming interface featuring Paradise Nursery branding, company background, and a "Get Started" navigation button.
- **Product Listing Page:** Displays categorized houseplants (Air Purifying Plants, Aromatic Fragrant Plants, Insect Repellent Plants) with dynamic "Add to Cart" buttons that disable once added.
- **Navigation Bar:** Persistent navbar across Product and Cart pages with links to Home, Plants, and a dynamic cart icon displaying total item count.
- **Shopping Cart Page:** Allows users to increment/decrement plant quantities, remove items, view individual and overall subtotals, continue shopping, or proceed to checkout.

## Technologies Used
- React.js
- Redux Toolkit (`@reduxjs/toolkit`, `react-redux`)
- CSS3
